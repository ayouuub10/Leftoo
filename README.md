# Lefto: Connecting Surplus & Support

Create a premium, production-ready mobile application called Lefto, designed specifically for Algeria, with a modern, elegant, and minimalist UI inspired by Airbnb, Uber Eats, Notion, and Apple Human Interface Design.

The application focuses ONLY on the current MVP:

Hotels publish food surplus.

Charitable organizations browse and request available food.

Platform administrators manage the entire ecosystem.

Do NOT include B2C, restaurants, event halls, supermarkets, or future roadmap features.
